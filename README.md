# React Performance: a tutorial project for the React course from RSSchool

Project "React Forms" is a training task within the course "React" from RSSchool, aimed at learning and working with modern tools and libraries React. The main focus is on creating forms using different approaches, state management, validation, testing and optimization of assembly.

## Project Goals

- **Mastering React:** Reinforce knowledge of components, state, props, hooks, and context.
- **Handling Large Data:** Process and display data from a large JSON file (~100MB) containing CO₂ emissions data by country.
- **Performance Optimization:** Apply **React.memo, useMemo,** and **useCallback** to minimize unnecessary re-renders.
- **Profiling:** Use React Dev Tools Profiler to analyze and improve application performance.

## How to Run the Project Locally

1. Clone the repo

```bash
   git clone https://github.com/Ekaterina-cat/REACT2025Q3.git

```

2. Install dependencies

```bash
   npm install
```

3. Start the development server

```bash
   npm run dev
```
