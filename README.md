# React Forms: a training project in RSSchool as part of the "React" course

Project "React Forms" is a training task within the course "React" from RSSchool, aimed at learning and working with modern tools and libraries React. The main focus is on creating forms using different approaches, state management, validation, testing and optimization of assembly.

## Project Goals

- **Learning React**: Mastering the core concepts and capabilities of React, including components, state, props, and hooks.
- **Environment Setup**: Configuring an optimal working environment for React applications.
- **Library Selection**: Using popular libraries to extend functionality (React Router, Redux, React Hook Form, Zod).
- **Build Optimization**: Using modern tools (Vite) to improve productivity and ease of development.

## How to Run the Project Locally

1. Clone the repo

```bash
   git clone https://github.com/Ekaterina-cat/REACT2025Q3.git

```

2. Install dependencies

```bash
   npm install
```

3. Start the development server

```bash
   npm run dev
